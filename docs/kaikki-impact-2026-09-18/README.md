# 词表与 Kaikki 分层导入：现有数据影响评估

日期：2026-09-18。此次只读扫描数据库及本地词典，未迁移生产数据。建议采用“外部词表决定收词和分级，Kaikki 提供词典内容”，但不能把 Kaikki 当作完整中文学习词典直接覆盖现有内容。

## 范围与方法

- 当前数据库有 18,451 个词、8,648 张关联词卡、16,873 条义项（覆盖 7,795 个词）、121,892 条复习记录；IELTS 标签覆盖 3,628 个词。
- 全量扫描 `server/scripts/data/kaikki.org-dictionary-English.jsonl`：3,245,973,435 字节、1,492,836 行。SHA-256：`e38fe0e9b53e3387673fe46429a02b3dcecfd3e5bf5771d7766c5afa6fd41f25`。本地修改时间不能证明上游快照日期。
- 覆盖率按 headword 区分大小写精确匹配，尚未递归解析拼写变体及词形。计数单位为词，每词至少有一项即计入，不代表其所有义项完整。
- 另外针对性抽查 34 个词及变体，涵盖多义、同形异义、主题词、专名、短语、英美拼写；不是随机抽样，不能据此估计全库错误率。
- 复现脚本：[audit.py](audit.py)；完整计数与抽查摘要：[results.json](results.json)。抽查原始条目保存在被 Git 忽略的数据目录 `server/scripts/data/kaikki-impact-2026-09-18/sample-records.json`。

## 实测覆盖

| 指标 | 全部现有词（18,451） | 现有 IELTS 词（3,628） |
|---|---:|---:|
| 精确匹配词条 | 18,305（99.2%） | 3,626（99.9%） |
| 有英文释义 | 18,303（99.2%） | 3,626（99.9%） |
| 有 IPA（任意地区） | 16,189（87.7%） | 3,571（98.4%） |
| 有至少一个中文译词（含顶层待消歧译词） | 12,070（65.4%） | 3,268（90.1%） |
| 有义项层中文译词 | 11,409（61.8%） | 3,088（85.1%） |
| 有任意例句记录（含引文、噪声） | 17,225（93.4%） | 3,573（98.5%） |
| 有初筛直接例句候选 | 10,843（58.8%） | 2,875（79.2%） |
| 同一候选义项同时有中文译词和直接例句 | 5,567（30.2%） | 1,855（51.1%） |

“初筛直接例句”要求义项有 gloss、不是 alt_of/form_of、未标 archaic/obsolete/historical/dated/rare/nonstandard，且例句 type=example、15–140 字符、不以词汇关系标记开头。这只是可复现的候选筛选，不是教学质量认证；合适引文及变体解析能补充覆盖。

当前所有词都有旧中文释义。若按精确匹配结果直接用 Kaikki 中文覆盖，6,381 个词（其中 IELTS 360 个）将没有中文。中文译词也不等于完整中文定义或例句中文翻译。应保留有来源标记的旧值，并报告缺失；别名解析后再重新计数。

IELTS 文件有 3,630 词，但数据库有 3,628 词：El Niño 被现有导入的字符过滤拒绝，shade-tolerant 没有 ECDICT 匹配。数据库精确匹配 Kaikki 的两个缺项是 fahrenheit（原始词典有 Fahrenheit，可建立映射）和 short-day。文件和数据库的大小写也有差别，不能混用分母。

## 抽查发现

| 词 | 现有内容或导入问题 | Kaikki 能提供什么；如何处理 |
|---|---|---|
| environment | 已存义项偏向计算机环境，漏掉自然环境 | 有自然生态环境义项及“环境”译词，但该义没有直接例句；无例句也应保留义项 |
| mantle | 当前中文未覆盖“地幔”，没有已存义项 | 有地质义项、地幔/地函地区译词及书籍引文；应选择雅思地理相关义项 |
| crust | 顶层译词未被当前脚本读取，关系说明可能混入例句 | 有地壳义项；中文“地壳”在顶层翻译中，要按 sense 提示消歧；Holonyms 不是例句 |
| record | 当前只存 3 个名词义项 | 原始数据有名词、形容词、动词共 16 义；可补“记录、录音”等，并保留对应发音 |
| issue | 当前取 glosses[0] 丢掉细化释义，例句偏旧义 | 原始数据含现代常用义，但也有大量旧义和口语例句；不能按源顺序选前三条 |
| resume / résumé | 同形及重音变体容易混淆词性、词义 | 应分别关联“继续”的动词义和“简历”的名词义；不能把别名跳转目标的全部义项照搬 |
| cricket | 昆虫与运动属于不同用法 | 两义均可找到；“蟋蟀”译词在顶层，“板球”在义项层，不能只读一处 |
| bow | 同拼写多词源、多发音 | 11 条原始记录、30 个义项，须保留词源及发音归属；不能压成一个发音和混排释义 |
| jeopardise / hybridisation | 英式拼写条目缺少直接的中文、音标等 | 通过明确的 alt_of 关联美式拼写；再匹配词性、领域、义项，不可盲目取目标第一义 |
| El Niño | 当前源词表收录但未入库 | 本地 Kaikki 有气候义项、中文和 IPA；修正收词规则后可以补入 |
| shade-tolerant | 当前源词表收录但未入库 | Kaikki 精确匹配也缺失；保留词表成员及待补全状态，不能因词典缺失而悄悄漏词 |
| Pacific / pacific | 当前小写词的中文混有太平洋专名与形容词 | 原始词典分开记录；不要全局小写合并 |

Kaikki 提供的是 Wiktionary 提取数据，仍有噪声和消歧错误。例如 bow 的部分义项中文关联需要人工核实，type=example 的句子也未必适合雅思学习。采用数据源和完成内容审核是两件事。

## 当前导入方式需要改变

现有 Kaikki 脚本只处理有卡片的词；同一拼写只取第一条有例句的记录，最多三个义项、每义两例；无例句的义项被舍弃；只取 glosses[0] 和义项内中文，未处理顶层中文。重新导入删除再创建义项，身份不稳定。这些规则是当前遗漏的重要原因。

建议保存完整来源记录，再产生适合学习的展示选择。不同词性/词源独立，常用义与雅思章节相关义优先显示；具体选择留可追溯依据。原始数据、人工校订、展示结果分开。

| 维度 | 建议来源及规则 | 对现状的影响 |

尚未选定并全量比对新词表，不能准确预测每级会新增/移除多少词。此次量化的是本地 Kaikki 对当前词库的覆盖。

## 对学习数据的影响与实施顺序

1. 固定词表与 Kaikki 的版本、哈希、来源及许可信息，生成 staging 差异报告。词表成员资格不依赖词典是否匹配成功。
2. 首先对上述抽查词实现多词性、多义项、中文映射、变体解析与例句筛选，再扩大至 IELTS 全集。缺项保留旧值且标为 legacy；不允许静默清空。
3. 迁移保留 Word.id、Card.id 及关联关系，校验 121,892 条历史复习记录、FSRS 和知识状态不变。词表成员变化不应直接删除用户卡片。
4. 同步维护 Word.translation/phonetic/pos、卡片背面和知识实体摘要，否则搜索、词表、复习页会显示不同内容。
5. 当前按词卡复习。补充词义本身不重置复习进度，也不能据旧卡熟练度宣称新增义项已掌握。若改为独立义项卡片，需要另行设计迁移。

详见 [导入规范草案](import-standard-draft.md)。上线前验收包括重跑幂等、缺项回退、别名多候选/循环处理、义项映射抽查、学习数据不变和回滚验证。
