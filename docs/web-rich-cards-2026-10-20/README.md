# Web 音频、公式和答案显示配置

本次接入已有后端接口，更新 Web 页面；Flutter App 工程保持原样。部署只更新静态资源，不需要数据库结构变更。

## 使用入口

- 牌组库 → 每张牌组卡片最右侧齿轮 →「复习展示」：配置自动播放音频、未学习新卡直接显示答案、自动显示答案的等待秒数。默认等待 10 秒；关闭后手动显示，重新开启默认恢复 10 秒。配置与每日限额一起保存，仅作用于该牌组。
- 进入牌组 →「添加」，或卡片表格每行右侧「编辑」：编辑正反面、内容格式和音频。
- 点击表格行展开详情，查看正反面、数学公式和音频；在列表和编辑预览中不会自动播放。

卡片编辑支持纯文本和 Markdown/数学公式。选择公式格式后，`\(...\)`、`\[...\]`、`$$...$$` 在预览中渲染，也可用「插入公式」包裹选中的文本。正反面均支持多行内容，保留输入的空白。预览错误会标明位置并阻止保存，网络或保存失败保留编辑内容供重试。

每面可选择多个 MP3、M4A、WAV、OGG/Opus 文件（每个最大 20 MiB），支持试听、上移/下移排序、切换所属卡面和移除。待添加文件先在本地预览，提交保存时上传；上传完成后保存失败，重试会复用已经上传的音频。移除是在保存时解除卡片关联，不会删除其他卡片使用的文件。

## 复习行为

Web 使用后端为每张卡片计算的 `presentation.answerRevealAfterMs`：`0` 为直接显示，正数为等待毫秒数，`null` 为手动显示。新卡立即显示优先于倒计时，撤销后按后台返回状态重新开始；队列完成后仍可撤销最后一次评分。

倒计时从卡片内容展示后开始。提前显示、切换卡片、撤销或退出会清理旧计时；切到后台暂停，回到前台按剩余时间继续。显示答案不会自动评分或自动切卡。公式加载失败时保留原文和重试入口，暂停自动显示，允许手动查看答案。

自动播放开启时，当前面的音频按顺序播放。翻面停止正面音频并播放背面；新卡直接显示答案只自动播放背面。切卡、撤销、退出或切到后台停止当前音频。所有播放器均保留手动控件；浏览器拒绝自动播放时提示用户手动点击。后台返回不会突然恢复播放。

原有英语音标/释义、日语假名/词性、例句及雅思用法继续使用原来的展示方式。只有显式标记为 `markdown_math` 的卡片采用后端生成的 HTML/MathML，不把用户原始文本直接当 HTML。公式 CSS 与字体由现有后端提供，渲染缓存限制数量和总大小。

## 验证

```bash
npm run build --prefix web
```

浏览器集成测试会创建、评分、撤销和清理临时卡片，必须连接数据库副本的本地预览服务，不能连接生产服务：

```bash
# 在后端使用临时 DB，Web 静态文件使用 web/dist 的预览服务上运行。
FLASHNEXT_TEST_BASE_URL=http://127.0.0.1:19005 \
FLASHNEXT_ALLOW_TEST_WRITES=1 \
npm run test:e2e --prefix web
```

测试使用 Playwright。优先使用 `CHROMIUM_PATH`，本机自动使用 `/usr/bin/chromium`；其他环境可先在 web 目录运行 `npx playwright install chromium`。测试输出目录已加入 Git 忽略规则。

10 项浏览器测试覆盖：牌组配置隔离、公式创建/编辑、音频上传/排序/移除、错误公式保护、默认 10 秒与关闭/立即显示优先级、手动评分与撤销、后台暂停、音频播放顺序与清理、自动播放拦截提示、手机宽度、过期预览响应和保存失败重试。另用实际英日词卡只读验证了原有读音释义显示，并对副本全部数据表核对，测试清理后原有记录保持一致。
