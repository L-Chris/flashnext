# 项目文档

Git 保留功能与接口说明、数据来源和授权依据、导入规则、可复用脚本及测试。英语词卡音频流程见 [英语音频维护](english-audio.md)。

高中概率牌组的内容、标签、先修顺序和导入方式见 [概率论牌组](probability-deck.md)。

生成进度、同步状态、配额检查、导入差异、迁移结果和浏览器检查报告属于本地运行产物，不提交 Git。新任务将这些文件写入 `server/scripts/data/<批次>/`，数据库及备份分别保存在 `server/data/` 和 `server/data-backup/`；这些路径均已忽略。临时文字记录可放在 `docs/local/`。

现有带日期目录中的来源说明、设计结论和复现脚本继续保留；其中 JSON/CSV 报告已取消跟踪，仅在本机保存。旧说明提到的这些文件是本地历史报告，其他机器需要重新运行对应脚本获得，不作为程序运行依赖。新的长期文档使用不带日期的主题文件名，具体执行日期和进度写入本地批次目录。

取消跟踪不删除本地文件，也不改写已推送的 Git 历史。可复用的数据资源（例如 `server/scripts/resources/` 中的来源清单与人工校订）仍需随代码提交。
